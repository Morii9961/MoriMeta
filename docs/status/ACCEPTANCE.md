# Morii 验收记录

这里只记 Morii 亲自试用后的结论。Agent 不能根据测试结果、代码或自己的判断在这里登记"验收通过"或"发现问题"。

## 怎么登记

在下表末尾加一行；旧行不删不改，同一里程碑以最后一行为准。

- **里程碑**：`PROJECT_STATUS.md` 中的编号（M01…）。只想说某个功能时，写编号再加功能名。
- **结论**只用三种：`待验收`、`验收通过`、`发现问题`。
- **说明**：发现问题时写清单编号（`research/MANUAL_TEST_PLAN.md` 中的 3.4 之类）、做了什么、看到什么、期望什么。**不要写真实照片路径、照片里的元数据值或个人信息**；日志和截图另外发。
- **登记人**：`Morii`；或 `Agent 转录`，并在说明里引用 Morii 在对话中的原话。
- 修好一个问题后，Agent 只能加一行 `待验收`（登记人 `Agent`，说明写修复提交），请 Morii 复验；复验的结论仍由 Morii 给出。

刷新快照时，最后一行的结论对应 `project-status.json` 的 `human_acceptance`：待验收 → `pending`，验收通过 → `accepted`，发现问题 → `rejected`。
