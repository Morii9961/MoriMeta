# Backend message inventory

> Generated by `python tools/message_inventory.py` from the Rust sources of the core crates (tests and the `mm-cli` development driver excluded). Input for choosing message codes with the design session (DESIGN_REVIEW_ENGINEERING §4); no codes are proposed here. "Embeds system/engine text" marks messages that carry an OS or ExifTool error verbatim: those need a code plus the raw text as a detail, not a translation. The scan finds texts at the places they are built (status, result and error constructors, notes) and in string constants used there (`shared`); a text kept in a variable first and passed on later is not listed.
