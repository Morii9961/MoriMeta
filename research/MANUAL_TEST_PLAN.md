# 手动试用清单（Morii，0.1.0 预览版）

工程端用脚本验证了应用（`apps/desktop/scripts/ui-smoke.mjs`、`release-check.mjs`、CI 的各项检查），但没有人亲眼看过、亲手用过它。这份清单给第一次手动试用用：按顺序走一遍，大约 1–2 小时。每一项写了“应该看到什么”；看到的不一样，就记下来（见末尾“出问题时”）。

## 0. 准备

**只用照片的副本。** 新建一个文件夹（例如 `D:\mm-test`），复制进去 20–50 张照片：几张普通 JPEG、几张 NEF（最好有一对同名的 `DSC_xxxx.NEF` + `DSC_xxxx.JPG`）、一张带 GPS 的、一张手机照片（HEIC 也行，应显示为只读/不支持）。不要用云同步文件夹（OneDrive 等）和 U 盘，那里的文件会被有意拒绝写入。

**拿到安装程序**（任选其一）：

- 最近一次 `release` 工作流（手动运行）的产物，保留 14 天：

  ```powershell
  gh run download <运行编号> -R Morii9961/MoriMeta -n release-files -D $env:TEMP\mm-release
  ```

  运行编号见 `gh run list -R Morii9961/MoriMeta --workflow release.yml`（选最新的、结论为 success 的那次）。没有可用的，就在 GitHub 网页的 Actions › release › Run workflow 手动运行一次（约 15 分钟）。
- 或推送 `v0.1.0` 标签，得到草稿发布（见 PROGRESS.md “First release”）。

**核对**：`Get-FileHash <安装程序> -Algorithm SHA256` 应与同目录 `SHA256SUMS.txt` 中的一致。安装程序未签名，SmartScreen 会拦：“更多信息” › “仍要运行”。

## 1. 安装与首次启动

| # | 操作 | 应该看到 |
|---|---|---|
| 1.1 | 运行安装程序 | 不弹管理员提示（UAC）；装到 `%LOCALAPPDATA%\MoriMeta` |
| 1.2 | 启动 MoriMeta | 首次启动向导：语言、备份位置、是否检查更新（三个选项都没有预选的“更新”） |
| 1.3 | 语言选中文，备份位置保持默认，更新选“从不” | 进入资料库，空状态提示添加照片 |
| 1.4 | 以管理员身份运行一次（右键 › 以管理员身份运行） | 应用能打开，但说明不会写入任何文件；之后正常启动 |

## 2. 添加与查看（不写入）

| # | 操作 | 应该看到 |
|---|---|---|
| 2.1 | Ctrl Shift O 添加 `D:\mm-test` | 扫描进度与剩余时间；表格列出所有文件，HEIC 等标为只读 |
| 2.2 | 点表头排序，Shift 点另一列 | 主次排序都生效 |
| 2.3 | 左侧分面、搜索框（Ctrl F）、“+ 添加条件” | 筛选结果正确；能保存为智能筛选 |
| 2.4 | 选中一个文件，按 I | 检查器：缩略图、每个字段的生效值与来源（EXIF/XMP/IPTC/sidecar） |
| 2.5 | 选中一个 NEF | 显示同名 `.xmp` sidecar（如有）中的值 |
| 2.6 | 文件资源管理器中看 `D:\mm-test` 的修改时间 | 到此为止没有任何文件被改动 |

## 3. 批量编辑 → 预览 → 应用

| # | 操作 | 应该看到 |
|---|---|---|
| 3.1 | 选中 5 个 JPEG + 2 个 NEF，作者“设置”为 `Morii`，版权用模板 `© {creator} {year}` | 暂存，尚未写入 |
| 3.2 | Ctrl Enter 预览 | 每个文件、每处修改；NEF 的修改写到 sidecar（没有的话“新建”）；预检通过 |
| 3.3 | 排除其中一个文件，再排除另一个文件中的一处修改 | 摘要中的数字随之变化 |
| 3.4 | 预览打开时，用别的软件改一下其中一个文件（例如另存一次） | 应用前被标出“读取后已改动”，需要重新规划 |
| 3.5 | 应用 | 进度；完成摘要；JPEG 被写入，NEF 本身的字节不变（修改时间不变），旁边多出 `.xmp` |
| 3.6 | 在 Windows 文件属性 › 详细信息 或其他看图软件中看作者/版权 | 是新值 |

## 4. 时间与 GPS

| # | 操作 | 应该看到 |
|---|---|---|
| 4.1 | 选几张，T 打开时间工具，“平移” +1 小时 | 预览中每张都晚 1 小时；UTC 偏移不变 |
| 4.2 | “序列”：起始时间 + 10 秒步长，按文件名 | NEF 与同名 JPG 共用同一个时间 |
| 4.3 | “绝对时间” | 预览中警告“顺序会丢失” |
| 4.4 | GPS 设置 `35.6586, 139.7454` 和 `35°39′31″N 139°44′43″E` | 两种写法都接受；错误写法给出具体提示 |
| 4.5 | 对 NEF“移除 GPS”（而 GPS 在 RAW 内） | 显示为不支持，并提示可用干净导出 |

## 5. 历史与撤销

| # | 操作 | 应该看到 |
|---|---|---|
| 5.1 | 打开“历史” | 刚才的每次操作都在 |
| 5.2 | 对第 3 节的操作“撤销…”全部 | 先列出冲突（如有）；完成后文件与原来逐字节一致，新建的 `.xmp` 被删除 |
| 5.3 | 撤销所选文件（只撤其中两个） | 只有这两个还原 |
| 5.4 | “将备份恢复到文件夹…” 到一个新文件夹 | 得到修改前的副本，原文件不动 |
| 5.5 | “导出日志…” | 日志中路径显示为 `asset#n.ext`；勾选项之外不含元数据值 |

## 出问题时

记下：第几项、做了什么、看到什么、期望什么；截图。然后附上：

- 历史 › 该操作 › “导出日志…”（先打开看一眼再发）；
- `%LOCALAPPDATA%\MoriMeta\logs\` 中当天的日志（不含路径、文件名和元数据值）；
- 如果问题可复现：设置 › 高级 › 打开调试日志，复现一次后再取日志（24 小时后自动关闭）。

可以直接在这次对话里贴给工程端，或开 GitHub issue。界面观感方面的意见（布局、颜色、措辞）记到单独一节，属于设计会话。

## 清理

试用结束后，可卸载并删除 `%LOCALAPPDATA%\MoriMeta`、`%LOCALAPPDATA%\org.morimeta.app` 和 `D:\mm-test`。
